# Screenshots Needed — Portfolio Landing

This top-level folder is for visuals that represent the **portfolio as a whole** (the main `README.md`), as opposed to project-specific shots — those live in each project's own `screenshots/` folder:

- [`voice-agent/screenshots/`](../voice-agent/screenshots/SCREENSHOTS_NEEDED.md)
- [`youtube-automation/screenshots/`](../youtube-automation/screenshots/SCREENSHOTS_NEEDED.md)
- [`social-media-automation/screenshots/`](../social-media-automation/screenshots/SCREENSHOTS_NEEDED.md)

Suggested portfolio-level visuals:

1. **`banner.png` — a portfolio banner / hero image**
   A clean header graphic for the top of the main README — "Aether AI · AI Automations" with the core logos (n8n, Claude, ElevenLabs, Twilio, fal.ai). Sets a professional first impression before a viewer reads a word.

2. **`stack-collage.png` — a one-image overview of all three systems**
   A 3-panel collage: a phone/voice agent, a YouTube video frame, and a Pinterest/Instagram reel — one glance that says "voice, video, social."

3. **`n8n-instance.png` — the n8n workflow list (optional)**
   A screenshot of the n8n instance showing multiple workflows, demonstrating these are real, deployed systems on a live instance. Blur any names/IDs you don't want public.

---

## What NOT to include

- Any **credentials, API keys, OAuth tokens, webhook URLs, or `$env` values** anywhere in any shot.
- **Real client / customer / brand data** — use synthetic data for any data-layer screenshot.
- **System prompts** or raw **Code-node source** from any project.

---

*Each project folder has its own, more detailed screenshot guide. Start with the per-project hero shots (a live call recording, a generated video frame) — those land hardest.*
